# 남의 사이트에 붙이기 (로그인 없는 공개 페이지)

우리 테스트베드 말고 **아무 공개 주소**에 페르소나를 풀어놓는 방법.

---

## 왜 되는가

**사이트의 HTML 코드를 받지 않습니다.** 진짜 크롬으로 페이지를 열고
화면에 그려진 것(DOM/CSSOM)에서 읽습니다. 요소에 붙는 이름표(`data-agent-id`)도
사이트에 있는 게 아니라 **우리가 실행 중에 붙입니다**(`uxagent/snapshot.py`).

공개 사이트 4곳에서 확인한 값:

| 사이트 | 응답 | 요소 | 이름 있음 | 이름표로 다시 짚기 |
|---|---|---|---|---|
| 자동화 연습용 쇼핑몰 | 200 | 3 | 3 | 3/3 |
| 자동화 연습용 상품목록 | 200 | 39 | 37 | 39/39 |
| MDN | 200 | 75 | 74 | 60/60 |
| 한국어 위키백과 | 200 | 3,079 | 2,911 | 60/60 |

---

## 쓰는 법

```powershell
# ① 답사 — 지도를 한 번 만든다 (LLM 씀)
python survey.py --url "https://example.com/shop" --max-pages 8

# ② 페르소나를 푼다
python run.py --url "https://example.com/shop" --limit 5 --max-usd 0.3 --run-id ex_01

# 지도 없이 바로 (덜 정확하지만 빠름)
python run.py --url "https://example.com/shop" --no-map --limit 3 --max-usd 0.2
```

`--url` 을 주면 `--variant` 는 무시됩니다. 기록은 호스트 이름으로 저장됩니다
(`maps/site_map_example.com.json`, `logs/ex_01/`).

**돈 안 쓰고 배선만 확인**하려면 `--mock` 을 붙이세요. LLM 을 부르지 않습니다.

## 자동으로 걸리는 안전장치

**범위 밖으로 안 나갑니다.** 준 주소의 **경로 아래**만 검사합니다.

```
--url https://webscraper.io/test-sites/e-commerce/allinone
  → 범위 https://webscraper.io/test-sites/e-commerce

  /test-sites/e-commerce/allinone/phones   안
  https://webscraper.io/                   안  (로고 눌러 첫 화면)
  /web-scraper-extension                   밖  ← 되돌림
  cloud.webscraper.io/register             밖  ← 되돌림
```

나갈 뻔한 횟수는 기록에 `left_scope` 로 남습니다 — 그것도 그 화면의 마찰입니다.

## 큰 사이트에서 무엇을 보는가

요소가 수천 개인 페이지가 있습니다(위키백과 3,079개). 프롬프트에는 25개만
들어가므로, **사람이 보는 순서**대로 고릅니다.

1. **지금 화면 안**을 위에서 아래로 — 사람도 스크롤한 만큼만 봅니다
2. 자리가 남으면 접힘선 **바로 아래**
3. 그래도 남으면 스크롤로 **지나간 위쪽**

페이지가 상한의 **3배를 넘을 때만** 추가로 손댑니다:
- 이름도 입력칸도 링크도 아닌 요소는 뺍니다 (눌러도 무엇인지 말할 수 없음)
- 같은 세로줄에 같은 높이로 반복되는 것(사이드바 차례, 메뉴)은 6개까지만

> 상품 카드는 접히지 않습니다. 격자에 놓여 왼쪽 끝이 칸마다 달라서입니다 —
> 상품은 하나하나가 다른 선택지라 접으면 안 됩니다.

**우리 테스트베드(20~40개)는 예전과 완전히 같습니다.** 앞서 쌓은 기록과
비교가 깨지지 않도록 일부러 그렇게 조였습니다.

## 아직 안 되는 것

| | 왜 |
|---|---|
| **로그인이 필요한 사이트** | 계정을 넣는 길이 없습니다. 로그인 벽에서는 요소가 3개만 잡힙니다 |
| **진짜 결제가 되는 사이트** | 페르소나가 '결제하기'를 누르면 실제 주문이 나갑니다. 안전장치가 없습니다 |
| **봇을 막는 사이트** | 확인한 4곳은 안 걸렸지만, 상용 커머스는 다릅니다 |
| **주소가 안 바뀌는 SPA** | 화면은 바뀌는데 URL이 그대로면 '같은 화면'으로 셉니다 |

**로그인 없는 공개 페이지**는 지금 됩니다.

## 확인용 도구

```powershell
# 이 주소가 될 만한지 미리 재보기 (LLM 안 씀, 크레딧 불필요)
python probe_public.py --url "https://example.com/shop"
```

요소 수 · 이름 있는 비율 · 이름표 재선택률 · 내부 링크 수 · 차단벽 여부를
`probe_public.json` 에 적어 줍니다. **답사를 돌리기 전에 이걸 먼저 보세요.**
