# 아무 사이트나 테스트해보기

주소 하나 던져놓고 **될지 안 될지 5분 안에** 판단하는 순서.

---

## 0. 먼저 알아둘 것 — 목표를 바꿔야 합니다

`personas/personas.json` 안에 목표가 하나 박혀 있습니다:

```
"코튼 셔츠를 장바구니에 담아 주문까지 마친다"
```

이걸 그대로 들고 나무위키에 가면 **100명이 위키에서 셔츠를 찾습니다.**
그래서 `--url` 을 쓸 때는 `--goal` 도 반드시 줘야 하고, 안 주면 실행이 막힙니다.

```
이 목표는 우리 테스트베드용입니다: '코튼 셔츠를 장바구니에 담아 주문까지 마친다'
  --url 로 다른 사이트를 검사할 때는 --goal 도 함께 주세요.
```

> `--goal` 은 **이번 실행에만** 적용됩니다. `personas.json` 은 안 건드립니다 —
> `generate.py` 를 다시 돌리면 사람이 통째로 바뀌어 앞서 쌓은 기록과
> 비교가 깨지기 때문입니다.

**좋은 목표 = 사이트에서 할 일 하나.** 결함을 적으면 안 됩니다.

| 사이트 | 좋은 목표 |
|---|---|
| 위키·문서 | `문서 안의 목차에서 항목 하나를 골라 그 부분을 연다` |
| 쇼핑몰 | `장바구니에 상품을 담아 주문까지 마친다` |
| 블로그·뉴스 | `최신 글 목록에서 글 하나를 열어 끝까지 읽는다` |
| 회사 사이트 | `문의하기 화면을 찾아 양식을 채운다` |

## 1단계 · 재보기 (30초, 돈 0원)

**LLM 을 부르지 않습니다.** 크레딧이 없어도 됩니다.

```powershell
cd C:\Users\kamdo\AI_Testing\agent-ux
python probe_public.py --url "https://검사할주소"
```

나온 표를 이렇게 읽습니다:

| 칸 | 뜻 | 좋은 값 |
|---|---|---|
| `응답` | HTTP 상태 | **200** |
| `막힘` | 차단벽·로그인벽 | **없음** |
| `요소` | 조작 가능한 것 개수 | 20 이상 |
| `이름있음` | 그중 무엇인지 알 수 있는 것 | 요소의 **80% 이상** |
| `다시짚기` | 우리 이름표로 되짚어지는 비율 | **60/60** (전부) |
| `내부링크` | 같은 사이트 안에서 갈 곳 | 5 이상 |

**여기서 걸러지는 것**

- `막힘 = cloudflare / captcha` → 봇 차단. **포기**
- `막힘 = 로그인벽`, `요소 3개` → 로그인 필요. **아직 안 됨**
- `요소 0~5개` → 자바스크립트로 늦게 그리는 화면. 될 수도, 안 될 수도
- `다시짚기`가 60/60 이 아니면 → 화면이 계속 바뀌는 사이트. 조작이 불안정

## 2단계 · 배선 확인 (2분, 돈 0원)

`--mock` 은 LLM 없이 루프만 돌립니다. 판단은 엉터리지만 **열리는지, 눌리는지,
범위를 안 벗어나는지**는 그대로 확인됩니다.

```powershell
python run.py --url "https://검사할주소" `
  --goal "여기에 목표" `
  --no-map --mock --limit 1 --run-id try_01
```

끝에 이렇게 나오면 배선은 정상입니다:

```
  [P001] loop_detected — 17스텝
  지도에 없던 화면 0회 / 허용 밖 행동 0회
```

> `loop_detected` 는 정상입니다. mock 은 첫 링크만 계속 누르기 때문입니다.
> **스텝이 돈다는 것 자체**가 확인 대상입니다.

기록 열어보기:

```powershell
python diary.py logs\try_01\P001.json
```

## 나무위키로 실제 재본 결과

```
응답 200 · 막힘 없음
요소 3,026개 · 이름있음 3,008 · 다시짚기 60/60 · 내부링크 3,037
로드 14.7초 (networkidle 미도달 — 계속 뭔가 불러오는 사이트)

--mock 으로 1명 실행: 17스텝 완주, 범위 이탈 3회 잡아 되돌림
문서 높이 19,444px · 본문 15px
```

**기술적으로는 됩니다.** 열리고, 요소가 잡히고, 이름표로 눌러집니다.

다만 이런 점을 알고 시작하세요:

| | |
|---|---|
| **요소 3,026개인데 25개만 봅니다** | 지금 화면 안을 위에서부터 봅니다. 사람과 같지만, 목차 같은 건 스크롤해야 나옵니다 |
| **문서 높이 19,444px** | 한 화면이 800px이니 스크롤 24번 거리입니다. 최대 스텝(25~35)을 다 써도 아래까지 못 갑니다 |
| **로드 14.7초** | 스텝마다 기다립니다. 1인당 시간이 테스트베드의 2~3배 |
| **목차 항목은 `#앵커`** | 주소가 안 바뀌어서 '같은 화면'으로 셉니다. 목표 달성 판정이 어렵습니다 |

> 나무위키는 **되긴 하지만 좋은 시연감은 아닙니다.** 문서가 너무 길고
> 화면 전환이 앵커라 흐름도에 아무것도 안 그려집니다.
> **화면이 여러 개로 나뉜 사이트**(쇼핑몰, 예약, 신청 양식)가 훨씬 잘 나옵니다.

## 안전장치 (자동)

**준 주소의 경로 아래만** 돌아다닙니다. 로고를 눌러 첫 화면 가는 것만 예외입니다.

```
--url https://namu.wiki/w/대한민국
  → 범위 https://namu.wiki/w

  https://namu.wiki/          안  (첫 화면)
  https://namu.wiki/w/서울     안
  https://namu.wiki/member/…  밖  ← 되돌림
  https://외부광고.com          밖  ← 되돌림
```

나갈 뻔한 횟수는 기록에 `left_scope` 로 남습니다.
