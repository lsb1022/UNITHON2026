## 4. 지금까지 된 것 / 안 된 것

**된 것**
- 페르소나 100명 재설계 (4축 x 1~5단계, 목표 하나, 축마다 20명씩)
- 답사 clean/buggy 양쪽 6/6 (실제 LLM, 스크린샷)
- `final_clean10` 10명 완료 — 달성 7 / 맴돌이 2 / 포기 1, $0.164
- `final_buggy10` **8/10 저장됨** — 달성 3 / 포기 4 / 맴돌이 1 (P008·P009 남음)
  clean 에서 달성했던 P004·P005·P010 이 buggy 에서 무너졌다
- 프론트 데모 껍데기: 백엔드 없이 전 구간 작동 (프로젝트→미션→페르소나→확인→진행률)
- 입력한 주소를 기억하도록 목업 수정

**안 된 것 (돌아와서 정할 것)**
1. **결과 모달** — 테스트 카드를 눌러도 라우트가 없어 목록으로 튕긴다.
   → 이미 만들어둔 `결과_한눈에.html` / `재생.html` / `replay-live.html` 을
   `PreviewModal` 에 iframe 으로 띄우는 안을 제안해둔 상태. 승인 대기.
2. **페르소나 화면 문구** — 프론트는 연령/성별인데 우리 축은 4축 1~5단계라
   "숙련도 - 상관없음 20" 처럼 어색하게 나온다.
3. **히트맵** — 어디를 제일 많이 눌렀는지 + 헛클릭 비율. 데이터는 이미 있고
   집계도 확인했다 (buggy 상품 페이지: '아이보리' 12회 중 9회가 헛클릭).
4. **경로 트리** — 같은 경로를 묶어 깔때기로 보여주기. 집계 확인 완료.
5. 커밋 — 오늘 프론트 목업 작업이 아직 커밋되지 않았다.

## 5. 손대면 안 되는 것

- `server/` — 팀원 백엔드. 연결은 나중에 하기로 했다.
- `web/` 의 팀원 파일 — 우리가 건드린 건 `src/api/client.ts`(5줄), `src/api/mock.ts`(새 파일),
  `src/api/mock-data.ts`(자동 생성) 셋뿐이다.
- `personas/personas.json` — 다시 만들면 앞선 결과와 사람이 달라져 비교가 깨진다.
