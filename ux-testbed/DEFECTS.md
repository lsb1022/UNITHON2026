# DEFECTS.md — 정답지 (Ground Truth)

`flawed/` 버전에 **의도적으로 심어둔 UX 결함 68개**의 전체 목록입니다.
소스 코드에 `[D-xx]` 형태로 주석이 달려 있으므로, 검증 결과와 1:1로 대조할 수 있습니다.

`clean/` 버전에는 이 중 어느 것도 존재하지 않습니다.
**clean에서 나온 지적은 원칙적으로 오탐(false positive)으로 집계하세요.**

## 채점 방법

```
Recall    = (검증 서비스가 flawed에서 찾아낸 결함 수) / 68
Precision = (실제 결함 지적 수) / (전체 지적 수)
FP rate   = (clean에서의 지적 수) / (clean 페이지 수)
```

심각도는 **Critical**(전환/구매 실패로 직결) > **High**(사용 불가 수준의 불편) > **Medium**(품질 저하) 순입니다.
