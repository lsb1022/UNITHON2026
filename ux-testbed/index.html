MOJI STORE — UX 검증 테스트베드

동일한 상품 데이터·동일한 구매 플로우 위에 만든 두 개의 쇼핑몰입니다. UX 검증 서비스가 무엇을 잡아내고 무엇을 놓치는지, 그리고 멀쩡한 화면을 문제로 오탐하지는 않는지 한 번에 측정하기 위한 A/B 픽스처입니다.

CLEAN — 기준선

정상 쇼핑몰

UX 베스트프랙티스를 지켜 만든 버전. 여기서 나오는 지적은 대부분 오탐(false positive)으로 봐야 합니다.

  • WCAG AA 대비 충족, 16px 본문
  • 44px 이상 터치 타깃, 가시적 포커스 링
  • 인라인 검증 + 에러 요약, 로딩 상태
  • 배송비 사전 고지, 비회원 구매 지원
CLEAN 열기 상품 목록
FLAWED — 탐지 대상

결함 쇼핑몰

실무에서 자주 발견되는 UX 결함 67개를 의도적으로 심었습니다. 각 결함은 소스에 [D-xx]로 주석 처리되어 있습니다.

  • 대비 1.9:1, 본문 11px, 포커스 링 제거
  • 20px 터치 타깃, div로 만든 가짜 버튼
  • 피드백·에러 메시지 없는 조용한 실패
  • 숨은 배송비, 기본 체크된 마케팅 동의
FLAWED 열기 상품 목록

검증 시나리오 (두 버전에 동일하게 적용)

  1. 홈 → 카테고리 필터 → 상품 상세 진입
  2. 색상·사이즈 선택 후 장바구니 담기 (결과 피드백이 있는가?)
  3. 장바구니에서 수량 변경 · 항목 삭제 (되돌릴 수 있는가?)
  4. 결제 화면에서 빈 값으로 제출 (무엇이 잘못됐는지 알려주는가?)
  5. 정상 입력 후 결제 → 주문 완료 (총액이 앞 단계와 일치하는가?)
  6. 품절 상품(워시드 후디 / 레더 벨트) 담기 시도
  7. 존재하지 않는 상품 ID로 접근: product.html?id=999
  8. 375px 폭 모바일 뷰포트로 전체 플로우 재실행
  9. 마우스 없이 Tab 키만으로 결제까지 완주 시도
